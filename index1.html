Ejercicio 1 · Invocar una función

Practica las funciones en el navegador.

Antes de empezar

Definir una función guarda unas instrucciones para reutilizarlas. Para ejecutarla debes invocarla: escribe su nombre seguido de paréntesis.

function saludar() {
  console.log("Buenos días");
}

saludar();

Tu turno

Abre este archivo con Live Server y la consola del navegador (F12 → Consola).

Invoca muestraGato para que aparezca Gato! en la consola. Escribe únicamente después de la función.
