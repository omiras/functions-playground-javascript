Ejercicio 4 · Interpretar una función booleana

Practica las funciones en el navegador.

Antes de empezar

Una comparación devuelve true o false. Si una función devuelve un booleano, su llamada puede ser la condición de un if.

function esMayorDeEdad(edad) {
  return edad >= 18;
}

if (esMayorDeEdad(20)) {
  console.log("Puede entrar");
} else {
  console.log("Todavía no puede entrar");
}
