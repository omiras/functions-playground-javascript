Ejercicio 9 · Mostrar un mensaje con alert

Practica las funciones en el navegador.

Antes de empezar

alert() es una función del navegador: muestra el valor recibido en una ventana emergente. Para pasar una variable, escribe su nombre sin comillas.

let saludo = "Buenos días";

alert(saludo);

Tu turno

Abre este archivo con Live Server y la consola del navegador (F12 → Consola).

Modifica únicamente la llamada a alert para mostrar el valor de mensaje en la ventana emergente.
