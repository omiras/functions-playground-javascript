Ejemplos de funciones JavaScript

Lee los ejemplos del script al final de este HTML y observa su resultado en la consola.

1. Usar funciones que ya existen

Una función realiza una tarea. Para ejecutarla, escribe su nombre seguido de paréntesis. Dentro puedes pasarle los valores que necesita, llamados argumentos.

parseInt("123") convierte ese texto en un número entero. console.log() muestra información en la consola. Math.random() devuelve un número aleatorio entre 0 (incluido) y 1 (excluido).

2. Crear y llamar a tus funciones

La palabra function permite definir una función. El código entre llaves se ejecuta cuando la llamas, no cuando la defines.

Los parámetros son los nombres que usa la función para recibir datos. Por ejemplo, suma(a, b) recibe dos valores y muestra su suma en la consola.

Observa la diferencia entre una función que siempre muestra el mismo mensaje y otra que recibe el mensaje como parámetro.

3. Devolver un valor y entender el ámbito

return devuelve un valor a quien llama a la función. Puedes guardarlo en una variable, mostrarlo o usarlo en otra operación.

console.log() muestra un mensaje; return entrega un resultado. Son tareas diferentes.

Una variable declarada con let dentro de una función solo está disponible dentro de ella. Los parámetros también son locales a la función.
