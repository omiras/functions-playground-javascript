Ejercicio 10 · Enlazar un script externo

Practica las funciones en el navegador.

Antes de empezar

La etiqueta script puede cargar un archivo JavaScript mediante el atributo src. Si la colocas antes de cerrar body, el HTML anterior ya estará disponible.

<body>
  <h1>Mi página</h1>

  <script src="otro-archivo.js"></script>
</body>

Tu turno

Abre este archivo con Live Server y la consola del navegador (F12 → Consola).

Enlaza script-externo.js al final de este HTML para ejecutar su código cuando cargue la página. No modifiques el archivo externo.
