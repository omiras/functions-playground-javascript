Antes de empezar

Math.random() devuelve un número desde 0 (incluido) hasta 1 (excluido). Math.floor() redondea hacia abajo. Combina estas herramientas para obtener un entero.

let decimal = Math.random();
console.log(decimal); // Desde 0 (incluido) hasta 1 (excluido).

let entero = Math.floor(3.8);
console.log(entero); // 3
