Ejercicio 5 · Simular un dado

Practica las funciones en el navegador.

Antes de empezar

Después de crear una función, puedes llamarla todas las veces que necesites usando argumentos diferentes.

function calcularAreaRectangulo(base, altura) {
  return base * altura;
}

console.log(calcularAreaRectangulo(5, 3));  // 15
console.log(calcularAreaRectangulo(8, 2));  // 16
console.log(calcularAreaRectangulo(4, 4));  // 16
