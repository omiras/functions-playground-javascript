Ejercicio 2 · Pasar valores y obtener un resultado

Practica las funciones en el navegador.

Antes de empezar

Los parámetros reciben los valores que pasamos al llamar a la función. return entrega un resultado que podemos guardar en una variable.

function doble(valor) {
  return valor * 2;
}

let total = doble(6);
console.log(total); // 12
