Ejercicio 3 · Reutilizar una función con un bucle

Practica las funciones en el navegador.

Antes de empezar

Una función puede combinar parámetros y bucles: un parámetro indica cuántas veces repetir y otro indica qué texto mostrar.

function contar(limite) {
  for (let i = 1; i <= limite; i++) {
    console.log(i);
  }
}

contar(3);
