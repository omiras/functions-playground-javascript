Ejercicio 7 · Calcular el área de una esfera

Practica las funciones en el navegador.

Antes de empezar

Una función puede realizar un cálculo con sus parámetros, guardar el resultado en una variable y devolverlo mediante return.

function calcularAreaRectangulo(base, altura) {
  let area = base * altura;
  return area;
}

console.log("El area de un rectangulo de anchura 10 y altura 20 es: ", calcularAreaRectangulo(10, 20));
